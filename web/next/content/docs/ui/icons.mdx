The icons come from [Remix Icon](https://remixicon.com), through `@remixicon/react`, always in their Fill variant, and the provider logos from [models.dev](https://models.dev).

## Effort

An agent's [effort](/docs/reference/agent) level: low, medium and high fill one, two and three bars of a cellular signal, and xhigh and max are two skulls, max the one with an open jaw.

| Level  | Icon                      | Component               |
| ------ | ------------------------- | ----------------------- |
| low    | <RiSignalCellular1Fill /> | `RiSignalCellular1Fill` |
| medium | <RiSignalCellular2Fill /> | `RiSignalCellular2Fill` |
| high   | <RiSignalCellular3Fill /> | `RiSignalCellular3Fill` |
| xhigh  | <RiSkullFill />           | `RiSkullFill`           |
| max    | <RiSkull2Fill />          | `RiSkull2Fill`          |

## Provider

The provider of an agent's [model](/docs/reference/agent), the part before the slash, drawn with its logo from models.dev in the text color. `bun run provider:logos` copies each logo into a component named after its provider, typed and sized like a Remix icon.

| Provider  | Icon          | Component   |
| --------- | ------------- | ----------- |
| anthropic | <Anthropic /> | `Anthropic` |
| zai       | <Zai />       | `Zai`       |

## State

The state an agent, a run or a task is in. The running icon spins, and stops for a reader who asks for reduced motion.

| State     | Icon                                                   | Component                |
| --------- | ------------------------------------------------------ | ------------------------ |
| cancelled | <RiForbidFill />                                       | `RiForbidFill`           |
| completed | <RiFlag2Fill />                                        | `RiFlag2Fill`            |
| failed    | <RiCloseCircleFill />                                  | `RiCloseCircleFill`      |
| idle      | <RiZzzFill />                                          | `RiZzzFill`              |
| paused    | <RiPauseCircleFill />                                  | `RiPauseCircleFill`      |
| pending   | <RiCalendarScheduleFill />                             | `RiCalendarScheduleFill` |
| running   | <RiLoader4Fill className="motion-safe:animate-spin" /> | `RiLoader4Fill`          |
| stuck     | <RiAlertFill />                                        | `RiAlertFill`            |
| waiting   | <RiTimeFill />                                         | `RiTimeFill`             |
