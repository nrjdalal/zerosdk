## Sections

Each agent row is one session and the agent it runs, an `Agent` and its `Session`, grouped by the agent's role. A subagent's session nests under the topmost subagent session above it on its `parentId` chain, however deep it was started. The orchestrators' and subagents' labels end with how many sessions they hold, nested ones included. The threads' label pages through them instead.

| Section       | Holds                                                                                             | Nests |
| ------------- | ------------------------------------------------------------------------------------------------- | ----- |
| Main agents   | The sessions of the agents at the top of the team, in the header where the docs keep search       | No    |
| Threads       | The human's [threads](#threads), five to a page, in the order given: most recently updated first  | No    |
| Orchestrators | The sessions of the persistent agents that each own one area of the work                          | No    |
| Subagents     | The sessions of agents started for one task, each with the sessions started under it nested below | Yes   |

## Row

A row reads from left to right.

| Part     | Shows                                                                                                                                                                                        |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Status   | The session's [task](/docs/ui/icons#task) while it runs, otherwise its [status](/docs/ui/icons#status); a closed row shows the first of its subagents that is running, and its own once open |
| Title    | The agent's name, or its description when it has none; a subagent's own row shows its session's title after the issue's key and pull request number, such as ZS-12#45 Add tools              |
| Provider | The [provider](/docs/ui/icons#provider) of the agent's model                                                                                                                                 |
| Effort   | The agent's [effort](/docs/ui/icons#effort) level                                                                                                                                            |

## Threads

A thread row shows less than an agent's: a main agent holds every thread, so its provider and effort would repeat on each one.

| Part   | Shows                                                                                                   |
| ------ | ------------------------------------------------------------------------------------------------------- |
| Status | The thread's [status](/docs/ui/icons#status): running, waiting, stuck, idle or completed                |
| Title  | What the human asked, which no update changes                                                           |
| Unread | How many of the thread's updates the human has not read, at the right, and nothing once all of them are |
| Menu   | The thread's actions, behind a ⋯ in the unread count's place                                            |

The menu groups its actions by what they do. It opens beside the sidebar, or below the row on a phone.

| Group      | Actions                                                              |
| ---------- | -------------------------------------------------------------------- |
| The thread | Mark as read, or Mark as unread once all are read; Rename; Pin; Fork |
| Sharing    | Export transcript; Share link                                        |
| Removing   | Archive; Delete, in the destructive style                            |

Past five threads, the label pages through them with an arrow on each side of the page number, such as 1/5, and each arrow stops at its end. While it pages, the list keeps five rows' height, so a short last page moves neither the arrows nor the groups below.

## Hover

Each part names what it shows: the status icon its task or status, the provider its model, and the effort its level. A row with subagents shows its toggle in its effort's place while the mouse is on it, while it has keyboard focus or is open, and always on a phone. A subagent's title names the agent running it, such as Builder: ZS-15 Fix login, and a name alone shows only when the row cuts it short. A thread's title names the agent holding it, such as AgentZero: Rewrite the pricing page copy, or AgentOne while it stands in. A thread's unread count gives way to its menu by the toggle's rules, so on a phone the menu shows and the count does not, and the menu stays while it is open.

## Selection

The first main agent is selected until another row is picked, a thread's included, as the sidebar holds one selection. A row's toggle opens and closes its subagents without changing the selection, and a closed row shows as selected while one of its subagents is.
